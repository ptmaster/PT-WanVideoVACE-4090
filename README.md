✨ 项目介绍
WanVideo VACE Encode 4090 是一个专为现代高性能 GPU 优化的 ComfyUI 节点包，旨在解决原版WanVideoWrapper中的 VACE 编码器在高分辨率分块模式下性能瓶颈的问题。经过 PT的辛勤调试和优化，这个节点让您的4090及更高级别显卡真正发挥其强大性能！

🎮 快速开始

安装方法

将本节点包放入 ComfyUI/custom_nodes/ 目录

重启 ComfyUI

在节点菜单中找到 WanVideo VACE Encode 4090

推荐配置

# 对于 4090D 24GB 显存

tile_size_multiplier = 2.0    # 平衡性能与质量

min_tile_size = 256          # 确保足够大的分块

# 对于1536 832以上的更高分辨率

tile_size_multiplier = 1.5    # 保守设置保证稳定性

min_tile_size = 192          # 适应高分辨率需求
